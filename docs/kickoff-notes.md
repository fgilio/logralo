# Logralo — daily goals app with streak counter and photo verification

Kickoff meeting notes — 2026-08-03.

# Concept Overview

- Goal-tracking app, web-first for fast iteration (no APK installs)
- Working name: “Logralo” (logralo.com taken but empty; logralo.app possibly available; fallback: Franco’s own domain)
- Initial version for the group only, expand if it works

# User Profiles and Goals

- Each user picks their own goals
- Goals are public within the group/team
- Goals categorized by type (exercise, food, personal, etc.)
  - Categories enable virality if opened to more users later
- Max 5 goals per user, at least one mandatory
- AI judges goal difficulty to weight completion fairly when money is involved
  - e.g. Guido’s goal worth 70% if it requires less willpower than Franco’s

# Core UX: One Screen, Frictionless

- App opens directly to today’s view, no menus
- Single-screen layout: columns = goals, rows = days
- Marking a goal done must be instant, no friction
  - Tap to mark complete
  - Hold to open camera or add a note
  - Swipe left/right to navigate to previous days or camera
- Photo required to log a goal (mandatory, key feature)
  - Can mark without photo, but not three times in a row
- Streak counter per goal: flame icon with day count
- Visual history: swipe back through days, see photos like a social feed

# Monetization and Engagement

- Entry fee (~$1-5) deposited into a monthly pool
- End of month: highest goal completion wins the pot
- Scoring by points first, then money once validated
- Pay to recover a lost streak
- Optional: pay to boost visibility or receive messages from followers
- Start free, add monetization once the core loop works
