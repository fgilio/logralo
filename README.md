# Logralo

Daily goals app with streak counter and photo verification, built for a group of friends. Mark a goal done with one tap, prove it with a photo, keep the flame alive.

Laravel 13 + Livewire 4 + Flux Pro + Tailwind 4, deployed on Laravel Cloud. Product notes live in [`docs/`](docs/); the technical kickoff guide lives in [`.claude/skills/logralo-kickoff/`](.claude/skills/logralo-kickoff/SKILL.md).

Note for contributors: the UI uses [Flux Pro](https://fluxui.dev), a paid component library, so `composer install` needs a Flux license. CI runs with the maintainer's license via repo secrets.
